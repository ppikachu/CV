## The Project
An interactive browser-based educational game developed for Pequeño Editor's digital platform. The game challenges young readers with progressive geographical and cultural puzzles across multiple world regions.

* **Interactive Mechanics:** Drag-and-drop tile alignment, state-driven feedback, and progressive difficulty tiers.
* **Lightweight Web Performance:** Built with native JavaScript and HTML5 Canvas for instant loading without external heavyweight runtime dependencies.
* **Child-Friendly UX:** Intuitive interface without textual friction, focusing on direct visual and sound feedback.
