**Tienda online de alta performance desarrollada con Nuxt 4, enfocada en la cultura pop y la experiencia de usuario.**

Kinoto es una plataforma de e-commerce de remeras y tote bags con diseños originales inspirados en la música, el cine y la cultura de culto. El proyecto fue concebido para ofrecer una experiencia de compra fluida y simple, combinando una estética moderna con una infraestructura técnica robusta.

## Stack
*   **Frontend:** Nuxt 4, Vue 3, Nuxt UI (Tailwind CSS 4).
*   **Estado:** Pinia con persistencia local.
*   **Integraciones:** MercadoPago (Pagos), PUDO (Logística), Resend (Email).

## Características Principales
*   **Arquitectura Moderna:** Implementación de las últimas capacidades de Nuxt 4, garantizando tiempos de carga mínimos y SEO optimizado.
*   **Ecosistema Transaccional:** Flujo de checkout completo integrado con pasarelas de pago y cálculo de envíos en tiempo real.
*   **Tracking de Precisión:** Medición avanzada mediante Google Analytics y **Meta Conversions API (Server-side)**.
*   **QR Analytics System:** Sistema personalizado de analíticas para marketing offline (stickers con QR).
*   **Automatización de Contenidos:** Generación inteligente de mockups y sistema de descubrimiento automático de imágenes por atributos (color/tipo).
